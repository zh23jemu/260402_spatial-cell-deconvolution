# 空间转录组细胞解卷积实验报告模板

## 1. 研究背景

- 介绍空间转录组与细胞解卷积问题
- 说明现有方法在仅用基因表达时的局限
- 引出“基因表达 + 空间位置”的必要性

## 2. 研究目标

- 输入：单细胞参考表达、空间表达和 spot 坐标
- 输出：每个 spot 的细胞类型比例
- 扩展：轻量跨域对齐，用于减弱平台差异

## 3. 数据集

### 3.1 Human Lymph Node

- `scRNA.h5ad`
- `ST.h5ad`
- `manual_GC_annot.csv`

### 3.2 Simulated seqFISH+

- `scRNA.h5ad`
- `Spatial.h5ad`

## 4. 方法

### 4.1 数据预处理

- 共享基因对齐
- 归一化与 `log1p`
- HVG 选择
- KNN 空间图构建
- pseudo-spot 构造

### 4.2 模型结构

- MLP 表达编码器
- GCN 空间聚合模块
- Softmax 比例输出层

### 4.3 基线方法

- NNLS
- MLP-only
